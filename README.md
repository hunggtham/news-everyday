# News Everyday

Daily curated news digest for **Vietnam 🇻🇳, South Korea 🇰🇷, the United States 🇺🇸**, plus major global developments.

## Update schedule

- Daily batch update: **08:00 Asia/Seoul (KST)**
- News is grouped by topic rather than by country.
- Each topic file contains sections for Vietnam, South Korea, the United States, and notable global news when relevant.
- **IT & AI are the highest-priority topics.**
- Duplicate articles about the same event should be clustered into one item.
- Every item should explain: what happened, why it matters, primary sources, and important English/Korean vocabulary.

## Entry format

Each daily section uses this structure:

```md
## YYYY-MM-DD

### 🇰🇷 South Korea
#### Headline
- **What happened:** ...
- **Why it matters:** ...
- **Sources:** ...
- **Keywords:**
  - `English term` — Vietnamese meaning
  - `한국어 용어` — Vietnamese meaning
```

If there is no meaningful news for a country/topic on a given day, do not add filler just to make the file look complete.
